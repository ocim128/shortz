# Plan: Text-to-Speech Feature (Edge TTS, 5 Indonesian Male Survival-Storyteller Voices)

## Context

ShortZ is a local Electron TikTok video editor (React + Zustand renderer, typed IPC bridge, all media work through ffmpeg child processes, strict dependency policy: no network-capable deps, network code only in `src/core/` behind host allow-lists). The user creates Indonesian TikTok content and needs text-to-speech narration with selectable voices. Decisions made with the user:

- **Engine: Edge TTS** (Microsoft's free neural voices via the `speech.platform.bing.com` WebSocket endpoint used by Edge Read Aloud). No API key, no cost. Base voice: **`id-ID-ArdiNeural`** — the only male Indonesian neural voice (mature, masculine ≈ 40s).
- **Scope: standalone "Speech" screen** (like Compress): text in → pick a voice → generate MP3 to the output folder. No editor/export integration in v1.
- **5 voices = 5 prosody presets** on Ardi (Edge TTS supports SSML `rate`/`pitch`/`volume` + `<break>` pauses), each tuned to a survival-storytelling register.

## The 5 voice presets (`VOICE_PRESETS`)

| id | Name | Character | rate | pitch | volume | sentence pause |
|---|---|---|---|---|---|---|
| `rimba` (default) | Rimba | Deep, deliberate jungle narrator | -10% | -8Hz | +0% | 650ms |
| `api-unggun` | Api Unggun | Slow, reflective campfire telling | -20% | -12Hz | +0% | 900ms |
| `detak` | Detak | Tense, urgent heartbeat pacing | +6% | +3Hz | +0% | 350ms |
| `badai` | Badai | Intense storm energy | +14% | +8Hz | +15% | 250ms |
| `fajar` | Fajar | Calm, exhausted dawn aftermath | -5% | -4Hz | +0% | 500ms |

All: male, masculine, mature, Indonesian (`id-ID`), dramatic pauses between sentences = storytelling feel.

## New files

**`src/shared/tts/voices.ts`** — `TtsVoicePreset` type + the 5-preset registry (renderer imports shared code directly, like DownloaderScreen does).

**`src/core/tts/ssml.ts`** (pure, unit-tested) — SSML builder: XML-escape text, split sentences (`/(?<=[.!?…])\s+/` + newlines), join with `<break time="{pauseMs}ms"/>`, wrap in `<speak xml:lang="id-ID"><voice name="id-ID-ArdiNeural"><prosody rate pitch volume>…</prosody></voice></speak>`. Single request per synthesis — no audio stitching needed.

**`src/core/tts/net/gec.ts`** (pure, unit-tested) — `Sec-MS-GEC` token: Windows filetime of now UTC floored to 5-min buckets → `sha256(ticks + "6A5AA1D4EAFF4E9FB37E23D68491D6F4")` uppercase hex (node:crypto).

**`src/core/tts/net/edge-tts-client.ts`** — WebSocket client following the `msedge-tts` reference protocol (current v2.1.x behavior): host allow-list (`speech.platform.bing.com` only, enforced before connect — mirrors `src/core/downloader/net/client.ts` policy), Edge-matching User-Agent + `chrome-extension://jdiccldimpdaibmpdkjnbmckianbfold` Origin, 403 → clock-skew correction + one retry, `speech.config` message with `outputFormat: audio-24khz-48kbitrate-mono-mp3`, then SSML message, collect binary audio frames until `turn.end`, 20s timeout, abort via AbortSignal. WebSocket via the **`ws`** package (zero transitive deps; Node 20 in Electron 33 has no stable global WebSocket).

**`src/core/tts/synthesize.ts`** — orchestration: validate text (non-empty, ≤10,000 chars), resolve preset, build SSML, call client, `atomicWriteFile` (reuse `src/core/store/fs-utils.ts`) the MP3 to target path. Returns `{ path, bytes, durationHint }`.

**`src/renderer/src/screens/Speech/SpeechScreen.tsx`** — following `CompressScreen.tsx`: back button + chip topbar; textarea with char counter; **voice list** — 5 rows (name, character description, ▶ preview button playing a per-voice cached sample via `<audio src="media://…">`); filename field (default = first sentence, sanitized); Generate button; running state with Cancel; result card (path, Play, Reveal in Explorer via existing `revealInExplorer`); error display.

**Tests** — `tests/unit/tts-ssml.test.ts` (escaping, breaks, prosody values per preset), `tests/unit/tts-voices.test.ts` (registry integrity), `tests/unit/tts-gec.test.ts` (fixed-timestamp token), `tests/integration/tts-client.test.ts` (hermetic: injectable socket factory against a fake, no network — same pattern as the downloader's `fetchImpl` injection).

## Risks (accepted)

- Edge TTS is an unofficial endpoint; Microsoft has changed auth before (Sec-MS-GEC, Dec 2025 UA requirement). Mitigation: client isolated in one file, protocol pinned to current `msedge-tts` behavior, clock-skew retry, graceful errors — swap-in of another provider later is a one-file change.
